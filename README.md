Proyecto de Landing Page de un smartwatch genérico 

1. Tecnologías utilizadas : HTML , CSS , Bootstrap 5
2. Se uso html semántico y clases pre-establecidas de Bootstrap 5.
3. El código se documentó de forma sencilla con comentarios para mayor entendimiento del lector.
4. Se desplegó el proyecto a través de la funcionalidad gratuita de github Page de github.
5. El proyecto es completamente responsivo y/o adaptable a dispositivos mobiles.
